# Learn Kotlin BN 🇧🇩

A native Bangla Kotlin learning platform for beginners and Android developers.

## 🚀 About This Project

This project has just started.  
More Kotlin learning resources, tutorials, Android guides, examples, and real-world projects will be added gradually.

Our goal is to make Kotlin learning easier for Bangla-speaking developers.

## 📚 Topics Covered

- Kotlin Basics
- Variables & Data Types
- Functions
- OOP Concepts
- Coroutines
- Android Development
- Jetpack Compose
- Practice Problems
- Real Project Tutorials

## 🛠 Tech Stack

- Kotlin
- Android Studio
- Next.js
- TypeScript
- Tailwind CSS
